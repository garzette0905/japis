# Jaden AI NEWS

주소: '/#/news', 메뉴: 개인서비스 → Jaden AI NEWS. 대시보드에도 같은 국내·해외 각 3개를 표시한다.

## 수집·표시 범위 (2026-10-05)

- 원문 매체: TechCrunch, AI타임스, The Information, Reuters, Bloomberg만 허용한다. 원문 URL의 실제 호스트를 검사해 재전재·다른 매체를 제외한다.
- URL 비교·최초 발행시각 캐시에 기사번호 쿼리(idxno 등)를 보존한다. utm·fbclid 같은 추적 파라미터만 제거해 AI타임스의 서로 다른 기사가 합쳐지는 것을 막는다.
- 공개 RSS/Atom을 사용하며 Reuters는 해당 도메인으로 한정한 Bing RSS 검색에서 원문 주소를 추출한다. 다른 매체의 피드 장애도 동일 매체로 한정한 검색으로 보완한다.
- 최초 보도 24시간 이내 AI 기사를 우선한다. 지역별 3개가 부족하면 최근 72시간까지 보완하고 카드·지역 제목 아래에 표시한다. 칼럼·행사·교육·주가 시황은 제외한다. 최초 시각을 KV에 기록해 수정된 기사를 새 보도로 오해하지 않는다.
- 같은 사건은 국내·해외 각각 제목 특징과 AI 사건 판정으로 묶는다. 한글 기사가 영문 대표 기사에 흡수되지 않도록 지역 간에는 합치지 않는다.
- 관련성·중요도 판정 후 Google News는 전체 제목 대신 핵심 단어 5개로 검색하고, 같은 사건의 결과 URL만 중복 제거해 센다. 지역별로 실제 선정 기간(기본 24시간, 부족하면 72시간)을 검색하며 결과는 최대 100건이다. 제목의 언어로 검색하므로 모든 언어의 보도를 전수 집계하지 않는다.
- 중요도 50% + Google News 확산도 30% + 최신성 20%로 지역별 점수를 매긴다. 중요도는 AI 판정 1~5의 비율이고, Google 점수는 보도 수의 log(1+n)을 해당 지역 최대값으로 정규화한다. 최신성은 최초 보도 기준 24시간 반감기다. 동률은 최신순이다.
- 국내 3개·해외 3개를 독립 선정한다. 해외는 점수 상위에서 서로 다른 매체를 먼저 선택하고 부족한 자리는 같은 매체로 채운다. 지정 매체 제한 때문에 국내는 AI타임스에서만 선정한다.
- AI 주제가 아니거나 중요도 3 미만인 기사는 제외한다. 판정 장애 시 규칙 필터와 출시·규제·보안 같은 사건 신호로 중요도를 보완한다. 72시간 안에도 적격 기사가 3개 미만이면 확보한 기사만 표시하고 경고한다.
- Google News 미등재 또는 확인 실패가 기사 탈락 사유가 되지 않는다. 확인 실패는 경고하고 중요도와 최신성으로 보완한다. Bing을 인기도 대체 지표로 사용하지 않는다.
- 영문 제목만 간결하게 한국어로 번역한다. 상위 목록·관련 보도·해외 참고 목록 모두 대상이다. 연속 JSON 객체·배열·코드블록을 안전하게 파싱하고 한국어 포함 여부를 검증한다. 같은 제목은 한 번만 번역하며 이전 스냅숏의 성공한 번역을 재사용한다.
- 번역 호출은 최대 2개 동시 실행한다. 배치에서 누락된 제목만 개별 재시도하고, 그래도 실패하면 전용 번역 모델 '@cf/meta/m2m100-1.2b'로 보완한다. 모든 단계 실패 시에만 원문 표시·경고를 유지한다.
- 국내 참고 기사와 해외 참고 기사는 각각 최대 10개, 최신순이다. Hacker News·공식 발표 목록은 수집하거나 표시하지 않는다.

## 운영

추가 시크릿·DB 변경은 없다. Workers AI 바인딩을 사용한다. 스냅숏은 'SESSIONS' KV의 'news:snapshot', 최초 시각은 'news:seen'이다. 스냅숏 버전 5부터 Google 검색 검증 상태와 캐시 복구를 적용한다.
매시 3분 예약 갱신, 캐시 유효 범위 65분, 수동 갱신 간격 10분. Google 요청은 1.5초 간격으로 직렬화하고 전체 연결은 최대 6개다. 수집 실패·번역 실패·인기도 확인 실패는 화면에 표시한다.

검증: 'npm test'. 출처 제한, Google 동일 사건 집계, 국내·해외 각 3개와 해외 매체 다양성, 72시간 보완 표시, 참고 목록 각 10개, 실제 연속 JSON 번역 오류·개별 재시도·전용 모델 복구·중복 제거·동시 호출 제한·캐시 재사용, 최초 시각·인증을 검증한다.

### Google News 확인 장애와 검증

- 동일한 검색 URL(언어·24/72시간 범위 포함)의 정상 RSS는 KV `news:google-results:v1`에 저장하고 1시간 재사용한다. Google 장애 때에는 최대 6시간 내 성공 결과를 사용하며, 현재 기간을 벗어난 보도는 다시 제외한다. 이전 확인 결과임을 카드와 경고에 표시한다.
- 403/429/503 또는 HTML 차단 응답이 재시도 후에도 계속되면 해당 지역의 남은 외부 검색을 중단한다. 캐시가 있는 검색은 계속 복구한다. HTTP 200 HTML을 정상 검색 0건으로 처리하지 않는다.
- 캐시도 없으면 Google 점수는 0으로 두며 중요도·최신성으로 선정한다. 카드의 반복적인 실패 문구는 제거하고 데이터 경고와 **순위를 매기는 기준 → Google News 검증 상태**에 실패를 표시한다. 실패를 성공이나 검색 0건으로 숨기지 않는다.
- 검증 상태에는 후보별 검색 링크, 정상/캐시/이전 결과/확인 불가, 동일 사건 보도 수, 성공 확인 시각, 오류 원인이 나온다. `/api/news`의 `googleDiagnostics`에서도 같은 정보를 볼 수 있다(기존 로그인·뉴스 권한 필요).
- 운영에서만 막히는지 비교하거나 최초 성공 캐시를 확보하려면 다음을 실행한다. `--seed` 없이 실행하면 읽기·검증만 한다. `--seed`는 검증에 성공한 Google RSS만 운영 KV에 저장하며 기존 다른 검색의 캐시를 보존한다. Windows PowerShell의 UTF-8 BOM도 지원한다.

```powershell
npx wrangler kv key get news:snapshot --binding SESSIONS --remote | Out-File -Encoding utf8 $env:TEMP/japis-news-snapshot.json
node tools/news-google-check.mjs --snapshot $env:TEMP/japis-news-snapshot.json
node tools/news-google-check.mjs --snapshot $env:TEMP/japis-news-snapshot.json --seed
```

캐시 저장 후 뉴스 화면의 새로고침을 누른다(기존 10분 수동 갱신 제한 유지). 이 도구는 자동 예약 작업이 아니며 지속적인 Google 차단을 영구적으로 해제하지 않는다. 캐시 유효기간이 지나면 확인 불가 상태를 다시 표시한다.

## 대시보드 (2026-10-03)

대시보드 순서: **AI 뉴스 국내·해외 각 3개**(같은 `/api/news`·같은 카드) → 입력칸 · 메일·할 일·일정 → **오늘의 Muse 요약**.
화면 바로가기 타일(개인서비스 이하)은 대시보드에서 뺐다(상단 메뉴에 같은 목록이 있다).
공유화면 목록은 `내 계정`으로 옮겼다.

### 오늘의 Muse 요약

`GET /api/wiki/briefing`(Jaden Memo 권한)이 이름에 `Muse`가 든 폴더(지금은 `Muse Daily`)에서 **가장 최근에 고친 메모 하나**를 날짜 제한 없이 준다. 그 폴더가 비었을 때만 최근 3일 안의
제목이 `데일리 브리핑`으로 시작하는 가장 새 메모로 대신한다.
본문은 메모 저장 때 씻은 html 이고 내보낼 때 한 번 더 씻는다. 지금은 사람이 붙여 넣으면 된다.
Muse 가 직접 넣으려면 아래 중 하나가 필요하다(아직 만들지 않음).

- Muse 가 HTTP 요청을 보낼 수 있으면: 토큰 하나(`MUSE_TOKEN` 시크릿)로만 열리는 `POST /api/muse/briefing` 을 두고 Muse 폴더에 메모로 저장.
- Muse 가 메일만 보낼 수 있으면: 브리핑을 JAPIS 에 연결된 Gmail 로도 보내게 하고, JAPIS 가 이미 쓰는 Gmail 연결로 제목 `데일리 브리핑` 메일을 읽어 보여준다.
