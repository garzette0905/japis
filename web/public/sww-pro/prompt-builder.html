사용 방법

  1. 문서 종류 선택, Prompt 입력, 추가 옵션('더보기' 클릭)을 선택합니다.
  2. "ChatGPT 열기"(Web/App) 또는 "Claude 열기"(Web/App)를 클릭하면 생성된 프롬프트가 클립보드에 복사되고 해당 서비스의 새 대화가 열립니다. App은 입력창에 프롬프트가 자동으로 채워집니다. (Codex, Claude Code, AI Pro, Antigravity는 "Prompt복사" 후 붙여 넣기)
  3. (AI 서비스 실행 후) Web은 입력창에 프롬프트를 붙여 넣기(Ctrl+V)하고, App은 채워진 프롬프트를 확인한 뒤, 첨부 파일이 있으면 업로드하고 전송합니다.
  4. 소스와 배포 정보는 버튼 목록 마지막의 "GitHub 저장소 열기"에서 확인할 수 있습니다.
