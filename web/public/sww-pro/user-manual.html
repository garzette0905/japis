SKILL GUIDE

Samsung Word Writer Pro 사용 설명서

기사·메모·이미지 등 원시 자료를 삼성 보고서 스타일의 Word(.docx) 문서로 자동 변환해주는 SKILL입니다. 처음 사용하시는 분도 아래 10가지 기능을 순서대로 따라 하면 바로 활용할 수 있습니다.

STEP 1

SKILL이란 무엇인가요?

SKILL의 일반적인 정의와 이 SKILL이 하는 일을 소개합니다.

SKILL의 정의

SKILL(스킬)은 AI(ChatGPT, Claude 등)에게 특정 작업을 정해진 방식·품질로 수행하는 방법을 가르쳐 놓은 "지침 패키지"입니다. 작업 절차, 문서 서식 규칙, 예제, 필요한 스크립트 등을 하나로 묶어 두고, 사용자가 스킬 이름을 호출하면 AI가 그 지침에 따라 일관된 결과물을 만들어 냅니다.

쉽게 말해, 매번 긴 지시문을 반복해서 입력하는 대신 "이 스킬대로 해줘" 한 마디로 전문가 수준의 작업 매뉴얼을 AI에게 통째로 전달하는 것입니다.

Samsung Word Writer Pro는 어떤 SKILL인가요?

기사 링크, 회의 메모, 이미지 등 어떤 형태의 원시 자료든 입력하면 삼성 보고서 스타일이 적용된 Word(.docx) 문서를 자동으로 생성·수정해 주는 스킬입니다.

  • 10가지 문서 유형 지원 : ① 언론기사·기술/제품개요 ② 시장동향·산업분석 ③ 주간 보고 ④ 현안 보고 ⑤ 개별 사업전략 ⑥ 기존 문서 수정(업데이트·오탈자·문서비교) ⑦ 기업개요 ⑧ CEO Profile ⑨ 전사 레벨 전략 ⑩ 지참자료·색인
    ※ ③ 주간 보고 옆 CEO 현안보고 체크박스를 켜면 팀장→CEO 1페이지 주간 업무현안 전용 양식(보고 주차·조직명·보고자·연간 주요업무·주간 업무 스토리 입력, 빈 항목은 'To Be Determined')으로 작성되고 보고 목적이 경영진 보고로 고정됩니다.
    ※ ⑦·⑧·⑩은 나머지 유형과 중복 선택이 가능합니다 (예: 시장동향 보고서 + 기업개요 별첨). ⑦·⑧은 주 유형 체크를 해제하고 단독 선택하면 기업개요·CEO Profile 단독 문서로도 만들 수 있습니다. ⑨ 전사 레벨 전략과 ⑩ 지참자료·색인은 보완중 유형이라 현재 Prompt Builder 화면에서 선택이 비활성 상태이며, 채팅으로 요청하면 작성됩니다.
  • 기존 문서 수정(⑥) : 작업 방식에 따라 세 가지 — 업데이트: 기존에 쓰던 보고서를 "표준문서"로 올리면 그 제목과 상위 목차(1./2. 또는 □)는 그대로 두고, 새로 첨부한 참고자료 데이터로 하위 내용만 다시 채워 줍니다 (예: 월별 실적보고 — 전월 보고서 양식에 이번 달 실적 반영). 오탈자만 수정: 내용·서식은 그대로 두고 오탈자만 고쳐 노란 하이라이트. 문서비교: Word 파일 2개(이전·최신)를 비교해 최신 버전 파일에 바뀐 부분만 노란 하이라이트로 표시합니다 — Word 2개가 없으면 비교하지 않고 알려주며, 바뀐 내용이 전체의 20% 이상이면 "많이 바뀌어 비교가 어렵다"고 알리고 멈춥니다. 모두 문서 첨부가 필수인 유형입니다
  • 삼성 보고서 서식 자동 적용 : 밑줄 강조, 파랑 9pt 주석(* ), 이동글틀(용어 설명 박스), 표 서식, 페이지 맞춤 등
  • 신규 생성뿐 아니라 기존 문서의 수정·검수(오탈자 교정, 두 버전 비교, 지침 준수 여부 점검)도 가능
TIP "이동글틀"이란 본문 중 어려운 용어·약어를 별도 박스로 풀어 설명하는 삼성 보고서 특유의 구성 요소입니다. 프롬프트에 "이동글틀 추가"라고 쓰면 자동으로 만들어 줍니다.
STEP 2

SKILL 접속 방법

ChatGPT, Claude, Antigravity, AI Pro 환경에서 사용할 수 있습니다. 호출·설치 방식만 조금 다릅니다.

1) ChatGPT에서 사용하기

  1. ChatGPT에 접속하여 로그인합니다.
  2. 채팅 입력창에 @를 입력하면 사용 가능한 스킬(GPT) 목록이 나타납니다.
  3. @samsung-word-writer-pro를 선택한 뒤, 이어서 요청 내용을 작성합니다.
ChatGPT 호출 예시
@samsung-word-writer-pro 스킬을 활용해서 아래 기사 내용을 정리해주세요.

2) Claude에서 사용하기

  1. Claude(claude.ai 또는 Claude Code)에 접속하여 로그인합니다.
  2. 채팅 입력창에 /를 입력하면 사용 가능한 스킬 목록이 나타납니다.
  3. /samsung-word-writer-pro를 선택한 뒤, 이어서 요청 내용을 작성합니다.
Claude 호출 예시
/samsung-word-writer-pro 스킬을 활용해서 아래 기사 내용을 정리해주세요.

3) AI Pro에서 사용하기

  1. AI Pro에 접속해서 로그인합니다. (VS Code에서 AI Pro Extension 접속)
  2. 채팅 입력창에 아래 설치 Prompt를 입력하여 Skill을 설치합니다.
  3. 또는 samsung-word-writer-pro 폴더를 직접 설치해도 됩니다.
AI Pro 설치 Prompt
GitHub에서 samsung-word-writer-pro 스킬을 내 PC의 AI Pro skills 폴더에 설치해주세요.


- 저장소: https://github.com/garzette0905/samsung-word-writer-pro
- 설치 위치: C:\Users\<내사용자명>\.aipro\skills\samsung-word-writer-pro
- 방식: git clone으로 해당 위치에 직접 내려받기 (파일 복사 방식은 사용하지 말 것)
- 설치 후 새 세션에서 Skill이 자동 로드됨을 안내할 것
정리 — ChatGPT에서는 @스킬이름, Claude에서는 /스킬이름으로 호출하고, AI Pro에서는 위 설치 Prompt로 git clone 설치 후 새 세션에서 자동 로드됩니다. 호출·설치 방식만 다를 뿐, 이후 프롬프트 작성 요령과 결과물은 동일합니다.

사용 방법 (4단계)

① 문서 유형 선택10가지 문서 유형(기사 정리, 시장동향, 주간보고, 기존 문서 수정, 기업개요 등) 중 만들고 싶은 유형을 고릅니다. ⑦ 기업개요·⑧ CEO Profile·⑩ 지참자료는 다른 유형과 함께 중복 선택할 수 있고, ⑦·⑧은 주 유형 체크를 해제하고 단독 선택하면 기업개요·CEO Profile 단독 문서로 작성됩니다.
② 옵션 입력Prompt 입력(최우선 반영)과 보고서내 도식 포함을 먼저 정하고, '더보기'를 누르면 문서 타이틀, 보고 목적, 작업 방식, 첨부파일 종류, 문서 수정사항 표시, 첫장 목차 페이지 설정, Word 파일 저장경로가 펼쳐집니다.
③ 프롬프트 자동 생성선택한 내용이 반영된 완성형 프롬프트가 화면에 자동으로 만들어집니다.
④ 열기 → 붙여 넣기 → 전송"ChatGPT 열기"(Web/App) 또는 "Claude 열기"(Web/App) 버튼을 누르면 생성된 프롬프트가 클립보드에 복사되고 해당 서비스의 새 대화가 열립니다. Web은 입력창에 붙여 넣기(Ctrl+V)하고, App(데스크톱 앱)은 입력창에 자동으로 채워진 프롬프트를 확인한 뒤 첨부가 있으면 올리고 전송합니다. (Codex·Claude Code·AI Pro·Antigravity는 "Prompt복사(Claude Code, AI Pro, Antigravity)" / "Prompt복사(Codex)" 후 붙여넣기) 소스와 배포 정보는 버튼 목록 마지막의 "GitHub 저장소 열기"에서 확인합니다.
보고 목적(독자)을 고르면 문서 깊이가 달라집니다 — 기본값은 팀장 보고입니다.
  • 경영진 보고 (임원·결재용) : 한 단계 더 깊게, □ 섹션 3~5개·1페이지 원칙. 핵심 요지를 앞에 두고 리스크·대응 → 실행 권고 → 최종 판단 한 줄로 마무리하며, 기업개요·CEO·상세표는 전부 별첨으로 뺍니다.
  • 팀장 보고 (관리자) : 유형 기본 깊이 유지, □ 섹션 5~7개, 현황 → 이슈 → 대응 균형 배치, 별첨 1~2개.
  • 실무 검토 (상세 내용 포함) : 해석은 최소화하고 사실·맥락을 앞에, □ 섹션 7개 이상도 허용, 상세표·원문 발췌 별첨과 이동글틀 용어정의를 늘립니다.
※ 이 보정은 ①·②·④·⑤·⑨ 유형에만 적용됩니다. ③ 주간보고, ⑥ 기존 문서 수정, ⑦ 기업개요, ⑧ CEO Profile, ⑩ 지참자료는 유형 고유 규칙이 우선합니다. 어느 보고 목적을 골라도 이동글틀은 페이지당 최소 3개 유지됩니다.
TIP 이 화면에서 프롬프트를 만들어 보면서 "좋은 프롬프트의 구조"(문서 유형 + 자료 + 목차 + 추가 요청)를 자연스럽게 익힐 수 있습니다. 익숙해지면 STEP 3~7의 예제처럼 직접 작성해도 됩니다.
⑥ 기존 문서 수정을 고르면 — '더보기'가 천천히 펼쳐진 뒤 작업 방식 목록이 이어서 열립니다. 첫 항목은 '문서 작업 선택'이며, 문서 수정/보완(업데이트, 목차유지) / 오탈자만 수정 / 문서비교 중 하나를 고르면 "Prompt 입력"란에 그에 맞는 안내 문구가 자동으로 채워집니다 (업데이트: "첨부 문서의 제목 및 상위레벨 목차는 유지하고 하위 내용을 지침에 맞게 변경해주세요…"). 그대로 써도 되고 상황에 맞게 고쳐도 됩니다. 다른 유형으로 바꾸면 '더보기'가 접히고 원래 안내 문구로 되돌아갑니다.
※ 이 유형은 문서 첨부가 필수입니다. 업데이트는 목차를 참고할 표준문서, 오탈자는 Word 1개, 문서비교는 Word 2개(이전·최신)가 없으면 스킬이 안내하고 작업을 멈춥니다. Prompt Builder는 파일을 ChatGPT·Claude로 전달하지 못하므로, 프롬프트 카드의 '문서 업로드 필요' 안내에 표시된 문서 수만큼 ChatGPT·Claude 입력창에서 직접 업로드한 뒤 전송해주세요. 문서비교는 바뀐 내용이 전체의 20% 이상이면 "많이 바뀌어 비교가 어렵다"고 알리고 멈춥니다.
STEP 9

보고서 도식(Diagram) 템플릿 13종

보고서 본문에 Word에서 직접 편집할 수 있는 네이티브 도형·화살표 도식을 넣을 수 있습니다. 아래 13가지 템플릿 중 내용 구조에 맞는 형태로 그려집니다.

도식을 넣는 방법

  • Prompt Builder에서 : "Prompt 입력" 오른쪽의 "보고서내 도식포함"을 체크하면 도식 포함 지시가 프롬프트에 자동으로 추가됩니다.
  • 채팅에서 직접 요청 : 프롬프트에 "… 구조를 도식으로 넣어주세요"처럼 한 줄 덧붙이면 됩니다. 템플릿 이름(예: hub_spoke, timeline)을 직접 지정해도 되고, 지정하지 않으면 내용에 맞는 템플릿을 스킬이 고릅니다.
  • 생성된 도식은 그림이 아니라 Word 네이티브 도형이므로, 문서에서 글자·색·위치를 바로 수정할 수 있습니다.
